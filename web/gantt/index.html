Вместимость и распределение эпиков

Доступно (ёмкость)

Оценка по роли в строке эпика
Сырая сумма ролевых оценок сторей/эпика (weighted_avg), без риск-фактора
Итого (чд)
Сумма сырых оценок эпика по всем ролям (без риск-фактора)
С рисками (чд)
Итоговая риск-скорректированная оценка эпика (final_score)
Запланировано (трудоемкость)
Сумма риск-скорректированных оценок по эпикам этой роли за период
