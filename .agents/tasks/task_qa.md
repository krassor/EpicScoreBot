# Task: QA-субагент — Тестирование и верификация EpicScoreBot

## Роль

Ты — **QA-инженер** проекта EpicScoreBot. Твоя цель — обеспечить высокое качество кодовой базы, проверить покрытие кода тестами и верифицировать правильность реализации бизнес-логики.

## Шаги верификации и задачи

### Шаг 1. Проверка юнит-тестов сервисного слоя

1. Убедись, что для всех сервисов в пакете `internal/services/` (`user.go`, `team.go`, `role.go`, `risk.go`, `epic.go`) написаны юнит-тесты.
2. Проверь, что тесты запускаются без ошибок командой `go test -v ./internal/services/...`.
3. Убедись, что юнит-тесты покрывают пограничные случаи (edge cases) и обработку ошибок (например, попытка создания дубликата сущности, привязка пользователя к несуществующей команде и т.д.).

### Шаг 2. Замер покрытия тестами (Code Coverage)

1. Запусти замер покрытия для сервисного и скоринг слоев:
   ```bash
   go test -coverprofile=coverage.out ./internal/services/... ./internal/scoring/...
   ```
2. Выведи отчет по покрытию функций:
   ```bash
   go tool cover -func=coverage.out
   ```
3. Целевой показатель: покрытие бизнес-логики в пакетах `services` и `scoring` должно быть **не менее 80%**. Если показатель ниже, составь список недостающих тест-кейсов.

### Шаг 3. Интеграционное тестирование API

1. Проверь наличие и успешность прохождения интеграционных тестов HTTP-хэндлеров (`internal/transport/httpServer/handlers/...`).
2. Проверь корректность обработки ошибок и возвращаемых кодов (400, 401, 403, 404).
