# gantt-reorder-modal Specification

## Purpose

Модалка «Порядок…» на диаграмме Ганта — общий интерфейс для изменения порядка эпиков, историй и ролевых задач в очереди конвейерного планировщика. Эта capability фиксирует требование о том, что модалка всегда показывает актуальный, а не закэшированный порядок.

## Requirements

### Requirement: Модалка «Порядок эпиков команды» показывает актуальный серверный порядок
При каждом открытии модалки «Порядок эпиков команды» система SHALL запрашивать текущий список эпиков команды с сервера, а не переиспользовать ранее загруженные и потенциально устаревшие данные. Порядок, отображаемый в модалке, SHALL соответствовать реальному состоянию на сервере на момент открытия, включая изменения, сохранённые через эту же модалку в текущем сеансе работы со страницей.

#### Scenario: Повторное открытие после сохранения показывает новый порядок
- **WHEN** пользователь изменил порядок эпиков через модалку, сохранил изменения, закрыл модалку и открыл её снова без перезагрузки страницы
- **THEN** модалка показывает порядок, соответствующий только что сохранённым изменениям, а не порядок, который был при первом открытии страницы

#### Scenario: Повторный reorder подряд без перезагрузки страницы
- **WHEN** пользователь выполняет reorder эпиков через модалку несколько раз подряд, не перезагружая страницу между попытками
- **THEN** каждое следующее открытие модалки использует результат предыдущего сохранения как отправную точку — сравнение новых номеров с исходными делается относительно актуального, а не устаревшего состояния
