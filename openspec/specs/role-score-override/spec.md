# role-score-override Specification

## Purpose

Позволяет администратору переопределить агрегированную оценку роли для стори одним действием (без правки оценки каждого участника этой роли по отдельности) и быстро подставить в переопределение финальной оценки стори значение, посчитанное по стандартной формуле, вместо расчёта его вручную.

## Requirements

### Requirement: Переопределение оценки роли для стори
Система SHALL позволять администратору (роль admin/superadmin, team-admin — только в пределах своей команды) напрямую задать агрегированную оценку конкретной роли для стори, статус которой `SCORED`, не изменяя при этом сохранённые оценки отдельных участников этой роли. Новое значение SHALL становиться тем значением, которое возвращается для этой роли по данной стори (в панели скоринга, отчётах и на любых других экранах, читающих агрегированную оценку роли), пока не будет переопределено повторно или пересчитано заново по оценкам участников.

Переопределение оценки роли SHALL не пересчитывать автоматически финальную оценку стори и не каскадироваться на родительский эпик — это отдельное, независимое от переопределения финальной оценки действие.

#### Scenario: Администратор переопределяет оценку роли
- **WHEN** администратор указывает новое значение оценки для конкретной роли уже полностью оценённой (`SCORED`) стори
- **THEN** система сохраняет новое значение как агрегированную оценку этой роли для стори; оценки участников этой роли не изменяются; финальная оценка стори не пересчитывается автоматически

#### Scenario: Попытка переопределить оценку роли для стори, скоринг которой не завершён
- **WHEN** администратор пытается переопределить оценку роли для стори, статус которой не `SCORED`
- **THEN** система отклоняет запрос с ошибкой о незавершённом скоринге и не изменяет данные

#### Scenario: Team-admin переопределяет оценку роли чужой команды
- **WHEN** пользователь с ролью team-admin (не superadmin) пытается переопределить оценку роли стори, принадлежащей команде, в которой он не является администратором
- **THEN** система отклоняет запрос как запрещённый (403) и не изменяет данные

### Requirement: Предпросмотр расчёта финальной оценки по формуле
Система SHALL предоставлять администратору способ получить значение финальной оценки стори, посчитанное по стандартной формуле (сумма оценок по ролям, скорректированная произведением коэффициентов риска стори, округлённая до целого), основанное на текущих сохранённых оценках по ролям (включая уже применённые переопределения ролей) и текущих оценках рисков стори — без сохранения результата в качестве финальной оценки стори.

#### Scenario: Администратор запрашивает предпросмотр расчёта
- **WHEN** администратор запрашивает пересчёт по формуле для стори в статусе `SCORED`
- **THEN** система возвращает значение, равное сумме текущих сохранённых оценок по всем ролям стори, умноженной на произведение коэффициентов риска по всем оценённым рискам стори, округлённое до целого, и не изменяет сохранённую финальную оценку стори

#### Scenario: Предпросмотр учитывает переопределённые оценки ролей
- **WHEN** одна или несколько ролей стори были переопределены администратором до запроса предпросмотра
- **THEN** расчёт предпросмотра использует переопределённые значения оценок этих ролей, а не значения, вычисленные из оценок участников

### Requirement: Кнопка «Пересчитать по формуле» рядом с переопределением финальной оценки стори
Панель скоринга стори SHALL показывать администратору управляющий элемент, который запускает предпросмотр расчёта финальной оценки по формуле и подставляет результат в поле ввода переопределения финальной оценки стори, не отправляя его на сохранение автоматически. Сохранение подставленного значения SHALL по-прежнему требовать отдельного явного действия администратора (существующая кнопка «Переопределить»).

#### Scenario: Пересчёт заполняет поле ввода, не сохраняя
- **WHEN** администратор нажимает кнопку пересчёта по формуле рядом с переопределением финальной оценки стори
- **THEN** поле ввода переопределения финальной оценки заполняется рассчитанным значением; финальная оценка стори остаётся неизменной, пока администратор не нажмёт «Переопределить»

### Requirement: Поле ввода и кнопка переопределения в строке роли
Таблица «Оценки по ролям» на панели скоринга стори SHALL показывать администратору в каждой строке роли поле ввода и управляющий элемент для переопределения оценки именно этой роли, не требуя перехода к таблице оценок участников.

#### Scenario: Администратор видит элемент переопределения в строке роли
- **WHEN** администратор с правом переопределения открывает панель скоринга стори в статусе `SCORED`
- **THEN** каждая строка таблицы «Оценки по ролям» содержит поле ввода и кнопку, позволяющие переопределить оценку именно этой роли

#### Scenario: Пользователь без права переопределения не видит элемент управления
- **WHEN** панель скоринга стори открывает пользователь без права администратора (обычный участник)
- **THEN** поле ввода и кнопка переопределения оценки роли не отображаются
