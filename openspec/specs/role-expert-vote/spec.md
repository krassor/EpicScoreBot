# role-expert-vote Specification

## Purpose

Позволяет администратору проставить экспертную оценку сразу для всей роли (всем участникам команды с этой ролью), пока скоринг стори/эпика ещё идёт, не вводя оценку за каждого участника этой роли по отдельности.

## Requirements

### Requirement: Массовое проставление оценки роли во время активного скоринга
Пока стори/эпик находится в статусе `SCORING`, система SHALL позволять администратору (роль admin/superadmin, team-admin — только в пределах своей команды) указать одну оценку для конкретной оцениваемой роли этого эпика, и SHALL применить эту оценку как поданный голос от имени каждого участника команды, имеющего эту роль. Уже поданные голоса участников этой роли (если есть) SHALL быть перезаписаны новым значением.

#### Scenario: Администратор проставляет экспертную оценку роли без личных голосов участников
- **WHEN** администратор указывает оценку для роли эпика, статус которого `SCORING`, и ни один участник этой роли ещё не голосовал
- **THEN** система сохраняет указанную оценку как голос каждого участника команды с этой ролью

#### Scenario: Экспертная оценка перезаписывает уже поданные личные голоса
- **WHEN** администратор указывает оценку для роли, по которой один или несколько участников уже успели проголосовать лично
- **THEN** система перезаписывает голоса всех участников этой роли новым значением, включая тех, кто уже голосовал

#### Scenario: У роли нет ни одного участника в команде
- **WHEN** администратор пытается проставить экспертную оценку для роли, которую в команде не занимает ни один участник
- **THEN** система отклоняет запрос с понятной ошибкой и не изменяет данные

#### Scenario: Попытка использовать для уже завершённого скоринга
- **WHEN** администратор пытается проставить экспертную оценку роли для эпика/стори в статусе `SCORED` (скоринг уже завершён)
- **THEN** система отклоняет запрос — для завершённого скоринга используется отдельный, уже существующий механизм переопределения оценки роли

### Requirement: Подтверждение перед перезаписью
Перед применением экспертной оценки роли система SHALL запросить у администратора подтверждение, явно предупреждающее о том, что действие перезапишет личные голоса участников этой роли, если они уже есть.

#### Scenario: Отмена подтверждения не изменяет данные
- **WHEN** администратор открывает диалог подтверждения экспертной оценки роли и отменяет его
- **THEN** голоса участников не изменяются, запрос на сервер не отправляется

### Requirement: Проставленные голоса учитываются в завершении скоринга как обычные
После массового проставления оценки роли система SHALL выполнить ту же проверку завершения скоринга, что и после любого обычного голоса участника — если это было последним недостающим условием (все ожидаемые участники всех ролей проголосовали и все риски оценены), эпик/стори SHALL перейти в статус `SCORED` автоматически, без дополнительных действий администратора.

#### Scenario: Экспертная оценка последней недостающей роли завершает скоринг
- **WHEN** все роли эпика, кроме одной, уже набрали все ожидаемые голоса и все риски оценены, и администратор проставляет экспертную оценку для оставшейся роли
- **THEN** эпик/стори переходит в статус `SCORED`, финальная оценка рассчитывается по обычной формуле

### Requirement: Список ролей для проставления оценки виден до завершения скоринга
Таблица «Оценки по ролям» на панели скоринга SHALL показывать все оцениваемые роли эпика (включая ещё не набравшие ни одного голоса) в течение всего времени, пока эпик/стори находится в статусе `SCORING`, а не только после завершения скоринга.

#### Scenario: Роли видны сразу после запуска скоринга
- **WHEN** скоринг эпика/стори только что запущен и ни один участник ещё не проголосовал
- **THEN** таблица «Оценки по ролям» показывает все оцениваемые роли этого эпика, а не пустой список
