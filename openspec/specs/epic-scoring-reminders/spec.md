## Purpose

Позволяет администратору вручную разослать напоминания участникам
команды, ещё не завершившим оценку эпика (трудоёмкость и/или риски), из
Telegram-бота или из веб-панели — с одинаковым критерием "кто ещё не
проголосовал" и одинаковым текстом напоминания независимо от источника
запуска.

## Requirements

### Requirement: Критерий "непроголосовавший участник"
Участник команды эпика SHALL считаться непроголосовавшим, если он не
проставил оценку трудоёмкости эпика ИЛИ у него остались неоценённые
риски эпика в статусе SCORING. Участник, полностью завершивший обе
оценки, SHALL быть исключён из списка получателей напоминания.

#### Scenario: Участник не оценил ни эпик, ни риски
- **WHEN** запускается рассылка напоминаний по эпику и участник команды
  не проставил оценку трудоёмкости эпика и не оценил ни один риск
- **THEN** участник получает напоминание, включающее и трудоёмкость
  эпика, и все неоценённые риски

#### Scenario: Участник оценил эпик, но не все риски
- **WHEN** участник проставил оценку трудоёмкости эпика, но не оценил
  один или несколько рисков этого эпика
- **THEN** участник получает напоминание только по неоценённым рискам

#### Scenario: Участник полностью завершил оценку
- **WHEN** участник проставил оценку трудоёмкости эпика и оценил все
  риски эпика в статусе SCORING
- **THEN** участник не получает напоминание и не учитывается в счётчике
  отправленных/неудачных сообщений

### Requirement: Рассылка напоминаний из Telegram-бота
Команда `/epicnotify` Telegram-бота SHALL рассылать напоминания
непроголосовавшим участникам выбранного эпика личными сообщениями и
сообщать инициатору итоговую сводку (число успешно отправленных и
список получателей, которым не удалось отправить сообщение).

#### Scenario: Успешная рассылка через бота
- **WHEN** admin выбирает эпик в статусе SCORING через `/epicnotify` и
  подтверждает рассылку
- **THEN** каждый непроголосовавший участник с известным chat ID получает
  личное сообщение, а admin получает сводку с числом отправленных
  сообщений

#### Scenario: Участник без начатого диалога с ботом
- **WHEN** у непроголосовавшего участника нет сохранённого chat ID
  (участник не начинал диалог с ботом)
- **THEN** сообщение ему не отправляется, участник попадает в список
  неудачных получателей сводки, рассылка остальным не прерывается

### Requirement: Рассылка напоминаний из веб-панели
Администратор (team-admin команды эпика или superadmin) SHALL иметь
возможность запустить рассылку напоминаний непроголосовавшим участникам
эпика со страницы скоринга веб-панели, с тем же критерием и текстом
напоминания, что и при рассылке через Telegram-бота. Действие SHALL быть
доступно только когда эпик находится в статусе SCORING.

#### Scenario: Admin запускает рассылку с веб-панели
- **WHEN** team-admin команды эпика (или superadmin) нажимает кнопку
  напоминания на странице скоринга для эпика в статусе SCORING
- **THEN** непроголосовавшие участники команды эпика получают личные
  сообщения в Telegram, а веб-панель отображает результат (число
  отправленных и не доставленных напоминаний)

#### Scenario: Admin чужой команды не может разослать напоминания
- **WHEN** team-admin, не являющийся администратором команды данного
  эпика, пытается запустить рассылку напоминаний для этого эпика
- **THEN** система отклоняет запрос с ошибкой доступа и не отправляет ни
  одного сообщения

#### Scenario: Попытка рассылки для эпика не в статусе SCORING
- **WHEN** запрашивается рассылка напоминаний для эпика, не находящегося
  в статусе SCORING
- **THEN** система отклоняет запрос с ошибкой валидации и не отправляет
  ни одного сообщения

#### Scenario: Кнопка недоступна пользователю без прав администратора
- **WHEN** участник без роли admin/superadmin просматривает страницу
  скоринга эпика
- **THEN** кнопка рассылки напоминаний не отображается
