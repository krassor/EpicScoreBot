Проверка: тест — задача ожидает задачу из эпика, стоящего в очереди позже, и получает корректный старт; при отсутствии ограничений второй проход не находит изменений и цикл останавливается.

Пересчёт не падает. Проверка: тест — снятие оценки по роли делает ссылку недействующей, возврат оценки возвращает её в силу, ограничение по дате всё это время работает.

Проверка: тест — порядок стори в выдаче совпадает с порядком на диаграмме для той же команды; роли внутри стори упорядочены так же, как там.
