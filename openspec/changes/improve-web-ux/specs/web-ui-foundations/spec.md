## Purpose

Фиксирует базовые свойства оболочки веб-интерфейса, общие для всех экранов: корректная иерархия заголовков документа для программной навигации, пригодные для касания размеры интерактивных элементов и единая терминология единиц измерения трудоёмкости.

## ADDED Requirements

### Requirement: Один главный заголовок документа

Страница веб-интерфейса SHALL содержать ровно один заголовок первого уровня — название приложения. Заголовки оверлейных экранов (авторизация, отказ в доступе) SHALL быть заголовками более низкого уровня, чтобы программная навигация по заголовкам не получала несколько конкурирующих главных заголовков.

#### Scenario: Иерархия заголовков при любом активном оверлее

- **WHEN** страница открыта в любом состоянии — экран авторизации, экран отказа в доступе или основное приложение
- **THEN** документ содержит ровно один заголовок первого уровня

### Requirement: Интерактивные элементы пригодны для касания

Интерактивные элементы интерфейса, включая иконочные кнопки закрытия модальных окон, SHALL иметь область нажатия не менее 40 пикселей по обеим сторонам на всех ширинах экрана. Адаптивные правила SHALL не искажать пропорции элемента: круглая кнопка остаётся круглой на любом брейкпоинте.

#### Scenario: Кнопка закрытия модалки на мобильном экране

- **WHEN** модальное окно открыто на экране шириной не более 768 пикселей
- **THEN** его иконочная кнопка закрытия имеет область нажатия не менее 40 пикселей по ширине и по высоте и остаётся круглой, а не вытянутой

#### Scenario: Кнопка закрытия модалки на десктопе

- **WHEN** модальное окно открыто на широком экране
- **THEN** область нажатия иконочной кнопки закрытия не меньше, чем на узком экране

### Requirement: Единая единица измерения трудоёмкости

Оценки трудоёмкости SHALL обозначаться во всём интерфейсе одной и той же единицей — человеко-днями («чд»). Иные сокращения для той же величины SHALL не использоваться.

#### Scenario: Список эпиков в панели инструментов диаграммы

- **WHEN** пользователь раскрывает выбор эпика в панели инструментов диаграммы Ганта и видит подписи с итоговой оценкой
- **THEN** оценка подписана «чд», как и на остальных экранах
