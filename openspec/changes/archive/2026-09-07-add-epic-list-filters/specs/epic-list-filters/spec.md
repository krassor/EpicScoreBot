## Purpose

Позволяет пользователю сузить список эпиков команды на панели скоринга по году, кварталу и типу эпика, не прокручивая весь список вручную.

## ADDED Requirements

### Requirement: Фильтры года, квартала и типа над списком эпиков
Колонка «Эпики команды» на панели скоринга SHALL показывать над списком эпиков три независимых фильтра: «Год», «Квартал», «Тип эпика». Список эпиков SHALL отображать только те эпики команды, которые удовлетворяют всем трём выбранным фильтрам одновременно.

#### Scenario: Фильтрация по одному параметру
- **WHEN** пользователь выбирает конкретное значение одного из фильтров (например, квартал Q2), оставляя остальные фильтры в значении «Все»
- **THEN** список показывает только эпики, у которых значение соответствующего поля (год/квартал/тип) совпадает с выбранным

#### Scenario: Комбинация нескольких фильтров
- **WHEN** пользователь одновременно выбирает конкретные значения в двух или трёх фильтрах
- **THEN** список показывает только эпики, удовлетворяющие всем выбранным значениям одновременно

### Requirement: «Все» — первый пункт и значение по умолчанию
В каждом из трёх фильтров пункт «Все» SHALL быть первым в списке вариантов выбора и SHALL быть выбран по умолчанию при открытии панели скоринга (до того, как пользователь изменил фильтр вручную). Выбор «Все» в фильтре SHALL означать отсутствие ограничения по этому параметру.

#### Scenario: Список эпиков без изменения фильтров
- **WHEN** пользователь открывает панель скоринга и не трогает фильтры
- **THEN** во всех трёх фильтрах выбрано «Все», и список показывает все эпики команды — как до появления фильтров

#### Scenario: Возврат к «Все» после выбора конкретного значения
- **WHEN** пользователь выбрал конкретное значение фильтра, а затем вернул его на «Все»
- **THEN** ограничение по этому параметру снимается, список пересчитывается с учётом оставшихся активных фильтров

### Requirement: Список значений фильтра «Год» строится по фактическим данным
Значения фильтра «Год» (кроме пункта «Все») SHALL соответствовать множеству различных годов, фактически присутствующих среди эпиков команды в текущей загруженной колонке — SHALL не быть статичным заранее заданным диапазоном лет.

#### Scenario: В команде есть эпики только одного года
- **WHEN** у всех эпиков команды одно и то же значение года
- **THEN** фильтр «Год» показывает пункт «Все» и ровно один пункт с этим годом

#### Scenario: У команды появились эпики нового года
- **WHEN** список эпиков команды содержит эпики нескольких разных лет
- **THEN** фильтр «Год» показывает пункт «Все» и по одному пункту на каждый встречающийся год
