## ADDED Requirements

### Requirement: Панель деталей стори отражает актуальный статус без перезагрузки страницы
После любого действия пользователя или администратора, в результате которого статус, финальная оценка или оценки по ролям выбранной стори меняются на сервере (например, отправка личного голоса, переопределение оценки, массовое проставление оценки роли), панель деталей SHALL повторно запросить и отобразить актуальное состояние этой стори без необходимости перезагружать страницу целиком. В частности, если действие переводит стория из статуса `SCORING` в `SCORED`, таблица «Оценки по ролям» SHALL сразу показать вариант для статуса `SCORED` (реальные агрегированные оценки по ролям), а не оставаться в варианте для `SCORING` (прочерки и элементы массового голосования).

#### Scenario: Массовое проставление оценки роли завершает скоринг стори
- **WHEN** администратор проставляет оценку роли всем участникам этой роли последним недостающим действием, и стория переходит в статус `SCORED`
- **THEN** без перезагрузки страницы таблица «Оценки по ролям» на панели деталей этой стори показывает реальные агрегированные оценки по каждой роли вместо прочерков, а элементы массового голосования по ролям больше не отображаются

#### Scenario: Личный голос завершает скоринг стори
- **WHEN** участник команды отправляет голос, который является последним недостающим для завершения скоринга стори, и стория переходит в статус `SCORED`
- **THEN** без перезагрузки страницы панель деталей этой стори отражает статус `SCORED` (финальная оценка, доступные администратору элементы переопределения) вместо устаревшего отображения статуса `SCORING`

#### Scenario: Действие не меняет статус стори
- **WHEN** пользователь выполняет действие, не изменяющее статус выбранной стори (например, повторный запрос данных без завершения скоринга)
- **THEN** панель деталей продолжает корректно отображать данные этой же стори, выбор стори в списке не сбрасывается и не переключается на другую сторю
