## ADDED Requirements

### Requirement: Оценка полностью покрытой роли видна до завершения скоринга
Пока стори/эпик находится в статусе `SCORING`, таблица «Оценки по ролям» SHALL показывать посчитанную агрегированную оценку для каждой роли, по которой уже проголосовали все ожидаемые участники команды с этой ролью, не дожидаясь перехода стори/эпика в статус `SCORED`. Показанное значение SHALL быть той же средневзвешенной по весам участников, которую система сохранит как агрегированную оценку этой роли при завершении скоринга, — так, чтобы при переходе в `SCORED` значение в этой ячейке не изменилось.

#### Scenario: Экспертная оценка роли сразу отражается в строке роли
- **WHEN** администратор проставляет экспертную оценку для роли, охватывающую всех участников команды с этой ролью, а другие роли эпика ещё не набрали все голоса (стори остаётся в статусе `SCORING`)
- **THEN** строка этой роли в таблице «Оценки по ролям» показывает проставленную оценку вместо прочерка

#### Scenario: Значение сохраняется после перезагрузки страницы
- **WHEN** пользователь перезагружает страницу, находясь на стори в статусе `SCORING`, у которой есть полностью покрытая голосами роль
- **THEN** строка этой роли по-прежнему показывает её оценку, а не прочерк

#### Scenario: Роль закрывается обычными личными голосами участников
- **WHEN** последний участник роли подаёт свой личный голос, и после этого проголосовали все участники этой роли, но скоринг стори в целом ещё не завершён
- **THEN** строка этой роли показывает средневзвешенную оценку по голосам её участников

#### Scenario: Значение не меняется при переходе в SCORED
- **WHEN** стори переходит в статус `SCORED` после того, как оценка полностью покрытой роли уже отображалась во время `SCORING`
- **THEN** в строке этой роли отображается то же самое значение, что и до перехода

### Requirement: Индикатор покрытия для не полностью оценённой роли
Пока стори/эпик находится в статусе `SCORING`, для роли, по которой проголосовали не все ожидаемые участники команды с этой ролью, таблица «Оценки по ролям» SHALL показывать прочерк вместо оценки и SHALL дополнительно показывать, сколько участников этой роли уже проголосовало из скольких ожидаемых. Промежуточное (посчитанное по неполному набору голосов) значение оценки для такой роли SHALL не отображаться, чтобы не выдавать неокончательную цифру за оценку роли.

#### Scenario: Роль оценена частично
- **WHEN** в команде два участника с ролью, и проголосовал только один из них
- **THEN** строка этой роли показывает прочерк и индикатор покрытия «1 из 2»

#### Scenario: По роли нет ни одного голоса
- **WHEN** ни один участник команды с этой ролью ещё не проголосовал
- **THEN** строка этой роли показывает прочерк и индикатор покрытия «0 из N», где N — число участников команды с этой ролью

#### Scenario: В команде нет участников с этой ролью
- **WHEN** роль указана как оцениваемая для эпика, но в команде нет ни одного участника с этой ролью
- **THEN** строка этой роли показывает прочерк и не показывает оценку — роль считается непокрытой

#### Scenario: Полностью покрытая роль не показывает индикатор
- **WHEN** по роли проголосовали все ожидаемые участники команды с этой ролью
- **THEN** строка этой роли показывает только её оценку, без индикатора покрытия

### Requirement: Действие «Оценить всей ролью» доступно и для уже покрытой роли
Пока стори/эпик находится в статусе `SCORING`, возможность проставить экспертную оценку роли SHALL оставаться доступной администратору для всех оцениваемых ролей, включая те, по которым уже проголосовали все ожидаемые участники, — чтобы исправить ошибочно проставленную оценку, не дожидаясь завершения скоринга. Отображение оценки роли SHALL не отменять и не скрывать это действие.

#### Scenario: Повторная экспертная оценка уже покрытой роли
- **WHEN** администратор проставляет новую экспертную оценку для роли, которая уже показывает своё значение в таблице
- **THEN** действие выполняется, и строка роли начинает показывать новое значение
