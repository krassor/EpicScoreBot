## Purpose

Позволяет участникам команды выгружать файлом (PDF или XLSX) отчёт по вместимости, квотам и оценённым эпикам команды за выбранный год и квартал прямо из веб-интерфейса, без обращения к Telegram-боту.

## ADDED Requirements

### Requirement: Выгрузка отчёта по команде в PDF
Система SHALL предоставлять авторизованному пользователю возможность скачать PDF-файл отчёта по команде за указанные год и квартал. Содержимое PDF-отчёта SHALL совпадать с отчётом, генерируемым для того же team_id/year/quarter через Telegram-бот (таблицы вместимости по ролям, недопланирование/перепланирование, квоты по типам задач, список эпиков с оценками).

#### Scenario: Успешная выгрузка PDF
- **WHEN** авторизованный участник команды запрашивает выгрузку отчёта в формате PDF для существующей команды и корректных года/квартала
- **THEN** система возвращает файл PDF с заголовком `Content-Disposition: attachment` и телом, содержащим отчёт по указанной команде/году/кварталу

#### Scenario: Отчёт за квартал без эпиков
- **WHEN** запрошены год/квартал, за который у команды нет ни одного эпика
- **THEN** система всё равно возвращает PDF-файл с таблицами вместимости и квот (без строк по эпикам), а не ошибку

### Requirement: Выгрузка отчёта по команде в XLSX
Система SHALL предоставлять авторизованному пользователю возможность скачать XLSX-файл с данными отчёта по команде за указанные год и квартал. Данные в XLSX SHALL соответствовать данным, возвращаемым JSON-эндпоинтом отчёта о вместимости (`/api/gantt/reports/capacity`) для тех же team_id/year/quarter: вместимость и план по ролям, недопланирование/перепланирование, квоты по типам задач, список эпиков с их оценками по ролям.

#### Scenario: Успешная выгрузка XLSX
- **WHEN** авторизованный участник команды запрашивает выгрузку отчёта в формате XLSX для существующей команды и корректных года/квартала
- **THEN** система возвращает файл XLSX с заголовком `Content-Disposition: attachment`, содержащий таблицы вместимости, квот и эпиков за указанный период

### Requirement: Параметры и валидация выгрузки отчёта
Система SHALL принимать параметры `team_id` (обязательный), `year`, `quarter`, `format` (`pdf` или `xlsx`, обязательный) и SHALL возвращать ошибку в стандартном формате `{ "error": { "code": "...", "message": "..." } }` при некорректных или отсутствующих обязательных параметрах, не поддерживаемом формате или несуществующей команде.

#### Scenario: Не указан team_id
- **WHEN** запрос на выгрузку отчёта не содержит `team_id`
- **THEN** система возвращает `400 Bad Request` со стандартной структурой ошибки

#### Scenario: Неподдерживаемый формат
- **WHEN** параметр `format` отсутствует или имеет значение, отличное от `pdf`/`xlsx`
- **THEN** система возвращает `400 Bad Request` со стандартной структурой ошибки

#### Scenario: Команда не найдена
- **WHEN** `team_id` указывает на несуществующую команду
- **THEN** система возвращает `404 Not Found` со стандартной структурой ошибки

#### Scenario: Год/квартал не указаны
- **WHEN** параметры `year` и/или `quarter` не переданы
- **THEN** система использует значения по умолчанию (текущий год и квартал), как это уже сделано в `/api/gantt/reports/capacity`

### Requirement: Доступ к выгрузке отчёта
Система SHALL разрешать выгрузку отчёта любому авторизованному через Telegram-аутентификацию пользователю (без ограничения по роли или принадлежности к конкретной команде), аналогично действующему доступу к `GET /api/gantt/reports/capacity`. Система SHALL отклонять запрос неаутентифицированного пользователя.

#### Scenario: Запрос без аутентификации
- **WHEN** запрос на выгрузку отчёта выполнен без валидной Telegram-аутентификации
- **THEN** система возвращает `401 Unauthorized`

### Requirement: Выгрузка отчёта из веб-интерфейса
Веб-интерфейс SHALL предоставлять на вкладке «Отчёты» элементы управления для скачивания текущего отчёта (по выбранным команде/году/кварталу) в форматах PDF и XLSX. Элементы управления SHALL быть недоступны (disabled), пока команда не выбрана.

#### Scenario: Скачивание из UI при выбранной команде
- **WHEN** пользователь выбрал команду, год и квартал на вкладке «Отчёты» и нажимает «Скачать PDF» (или «Скачать Excel»)
- **THEN** браузер инициирует скачивание файла отчёта в выбранном формате для текущих значений фильтров

#### Scenario: Кнопки скачивания без выбранной команды
- **WHEN** на вкладке «Отчёты» не выбрана команда
- **THEN** кнопки «Скачать PDF» и «Скачать Excel» недоступны для нажатия
